1. O Desafio do Desbalanceamento Severo em Dados Reais

O dataset de transações de cartão de crédito contém 284.807 registros coletados em setembro de 2013 por portadores de cartões europeus. Dentre todas as operações registradas ao longo de dois dias, apenas 492 transações foram identificadas como fraudulentas, correspondendo a meros 0,172% da base.

Por que a Acurácia Engana?

Se construirmos um modelo "burro" que simplesmente preveja a classe 0 (Legítima) para qualquer transação, esse modelo alcançará matematicamente uma acurácia de 99,828%. No entanto, seu valor para o banco é rigorosamente zero, pois nenhuma fraude será detectada. Por este motivo, as métricas de sucesso em detecção de fraude são:

  • Recall: Taxa de fraude real capturada sobre o total de fraudes ocorridas.
  • Precisão: Proporção de transações bloqueadas que eram de fato criminosas.
  • PR-AUC: Área sob a curva Precision-Recall, imune ao desbalanceamento excessivo de zeros.

2. Engenharia de Recursos (Feature Engineering)

As variáveis V1 a V28 já foram transformadas pela técnica de Análise de Componentes Principais (PCA) para garantia de confidencialidade dos dados dos usuários. As únicas variáveis que mantiveram seus valores originais brutos são Time e Amount.

Transformação Logarítmica (Log_Amount) A variável de valor monetário possui cauda longa extrema (desde compras de R$ 0,01 até compras de R$ 25.000,00). A aplicação de np.log1p(df['Amount']) achata os outliers sem perder a relação de ordem.
Padronização com StandardScaler Como as variáveis PCA já possuem média zero e variância unitária, o StandardScaler foi aplicado em Time e Log_Amount para colocá-las no mesmo plano vetorial.

🐍 Script Python Completo (Pronto para Colab / Produção) 

import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import recall_score, precision_score, f1_score, average_precision_score
import shap

# 1. Carregamento dos dados
url = "https://storage.googleapis.com/download.tensorflow.org/data/creditcard.csv"
df = pd.read_csv(url)

# 2. Feature Engineering
df_proc = df.copy()
df_proc['Log_Amount'] = np.log1p(df_proc['Amount'])

scaler = StandardScaler()
df_proc['Scaled_Time'] = scaler.fit_transform(df_proc[['Time']])
df_proc['Scaled_Amount'] = scaler.fit_transform(df_proc[['Log_Amount']])

X = df_proc.drop(columns=['Time', 'Amount', 'Log_Amount', 'Class'])
y = df_proc['Class']

# 3. Divisão Estratificada
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.20, random_state=42, stratify=y
)

# 4. Treinamento do Modelo Campeão (Random Forest com Balanceamento)
modelo = RandomForestClassifier(
    n_estimators=100, class_weight='balanced', max_depth=10, n_jobs=-1, random_state=42
)
modelo.fit(X_train, y_train)

# 5. Predição com Limiar Calibrado (Threshold = 0.35)
probabilidades = modelo.predict_proba(X_test)[:, 1]
predicoes_calibradas = (probabilidades >= 0.35).astype(int)

# 6. Avaliação
print("Recall da Fraude:", recall_score(y_test, predicoes_calibradas))
print("Precisão da Fraude:", precision_score(y_test, predicoes_calibradas))
print("F1-Score:", f1_score(y_test, predicoes_calibradas))
print("PR-AUC:", average_precision_score(y_test, probabilidades))

# 7. Explicabilidade SHAP
amostra = X_test.sample(n=200, random_state=42)
explainer = shap.TreeExplainer(modelo)
shap_values = explainer.shap_values(amostra)
print("Pipeline finalizado com sucesso!")
